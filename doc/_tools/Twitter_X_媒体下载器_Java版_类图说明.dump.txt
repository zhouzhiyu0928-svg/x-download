P006 [(none)] 本文档对系统核心类的职责、主要属性与方法、以及类之间的关系进行说明，作为详细设计的补充，便于开发时理解对象协作方式。类图以文字 + 关系描述形式呈现，可直接用于绘制 UML 类图或指导编码。
P007 [Heading 1] 2. 总体类关系概览
P008 [(none)] 系统核心协作关系可概括为：
P009 [(none)] • CLI 命令类创建并配置 Task，交给 TaskScheduler 执行。
P010 [(none)] • Task 通过 TaskContext 使用 GraphQLClient、MediaDownloader、DownloadRecordRepository 等。
P011 [(none)] • GraphQLClient 依赖 AccountPool、RateLimiter、TransactionIdGenerator 完成请求。
P012 [(none)] • MediaDownloader 依赖 NamingTemplate 生成路径，并将结果写入 Repository。
P013 [(none)] • 配置由 ConfigLoader 加载为 AppConfig，注入到各组件。
P014 [Heading 1] 3. 交互层类
P015 [Heading 2] 3.1 MainCommand / 各子命令
P016 [(none)] 职责：解析命令行参数，加载配置，组装依赖，创建对应 Task 并提交 TaskScheduler。
TABLE0 rows=7 cols=2

   R04 | ReplyCommand | 评论区下载子命令，参数：user 或 tweet-url

   R06 | ProfileCommand | 用户主页信息下载子命令
P017 [(none)] 关系：各 Command 依赖 ConfigLoader、TaskScheduler；创建具体 Task 实例。

P119 [Heading 1] 8. 领域模型类
TABLE2 rows=7 cols=2
   R00 | 类名 | 说明
   R01 | User | 用户信息：screenName、restId、name、avatarUrl、bannerUrl、description 等
   R02 | Tweet | 推文：tweetId、text、createdAt、user、mediaItems、isRetweet、metrics 等

P120 [(none)] 关系：Tweet 包含多个 MediaItem；User 与 Tweet 关联；DownloadRecord 由 MediaItem 下载结果生成。
