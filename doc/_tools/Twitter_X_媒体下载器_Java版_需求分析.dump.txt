P005 [Heading 1] 1. 项目概述
P006 [Heading 2] 1.1 项目背景
P007 [(none)] 本项目基于 GitHub 开源项目 twitter_download（https://github.com/caolvchong-top/twitter_download）的功能进行 Java 语言重写与扩展开发。该项目通过 X（原 Twitter）非官方 GraphQL 接口，结合用户 Cookie 认证，实现推文媒体（图片、视频、GIF）及文本内容的批量下载。本项目在完整保留其核心能力的基础上，采用 Java 技术栈重新实现，并进一步提升工程化水平与使用体验。
P008 [Heading 2] 1.2 项目目标
P009 [(none)] 1. 使用 Java 完整实现 twitter_download 的全部核心功能。
P010 [(none)] 2. 构建统一、模块化的任务体系，支持用户媒体、Tag 搜索、评论区、纯文本、用户主页等多种下载模式。
P011 [(none)] 3. 提供多账号 Cookie 管理、代理支持、请求限流、增量同步、断点续传等工程化能力。
P012 [(none)] 4. 提供清晰的配置方式与命令行交互，方便用户使用与二次开发。
P013 [(none)] 5. 项目定位为本地个人学习与研究工具，严格遵守相关平台服务条款与法律法规。
P014 [Heading 2] 1.3 成功标准
P015 [(none)] • 能够稳定下载指定用户推文中的图片、视频与 GIF，支持排除转推、时间范围过滤与增量同步。
P016 [(none)] • 支持按 Tag / 高级搜索、评论区、纯文本、用户主页内容下载。
P017 [(none)] • 支持多账号 Cookie 池与代理，具备完善的限流与重试机制。
P018 [(none)] • 配置清晰、日志完整，支持断点续传与失败重试。
P019 [(none)] • 提供可执行程序包与完整使用文档。
P020 [Heading 1] 2. 用户与使用场景
P021 [Heading 2] 2.1 目标用户
P022 [(none)] • 个人研究者、内容归档爱好者。
P023 [(none)] • 具备基本命令行操作能力、能够自行获取浏览器 Cookie 的开发者或技术用户。
P024 [Heading 2] 2.2 主要使用场景
P025 [(none)] 1. 下载单个或多个用户的媒体时间线（可排除转推、指定时间范围）。
P026 [(none)] 2. 按 Tag 或高级搜索条件批量下载相关媒体内容。
P027 [(none)] 3. 下载指定用户或指定推文的评论区媒体。
P028 [(none)] 4. 获取指定用户的纯文本推文或主页信息（头像、banner、简介）。
P029 [(none)] 5. 对已下载用户进行增量更新，仅获取新增内容。
P030 [(none)] 6. 在多账号与代理环境下执行长时间批量下载任务。
P031 [Heading 2] 2.3 非目标场景
P032 [(none)] • 大规模商业数据采集。
P033 [(none)] • 实时流式监听或自动化互动（发帖、点赞等）。
P034 [(none)] • 依赖官方付费 X API 的方案。
