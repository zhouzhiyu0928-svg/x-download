X Media Downloader

基于 twitter_download 功能的 Java 重写版本地媒体下载工具，支持用户、Tag、评论区、纯文本与主页内容。

Java 17+ OkHttp · Jackson · SQLite CLI · 多账号 · 增量同步 v1.0 Design

核心能力

  • 按用户下载推文中的图片、视频、GIF，支持排除转推、时间范围与增量同步
  • 按 Tag / 高级搜索批量下载媒体，可选保存文本
  • 下载指定用户或推文的评论区媒体
  • 获取纯文本推文与用户主页信息（头像、Banner、简介）
  • 多账号 Cookie 池、代理、请求限流与自动重试
  • SQLite 记录下载状态，支持断点续传与失败重试
  • 可配置命名模板与清晰 CLI 子命令

快速开始（设计约定）

# 用户媒体下载 java -jar x-media-downloader.jar user \ --users elonmusk,openai \ --config config.yaml # Tag / 高级搜索 java -jar x-media-downloader.jar tag \ --tag "#example" \ --config config.yaml # 评论区 java -jar x-media-downloader.jar reply \ --tweet https://x.com/user/status/123

分层架构

交互层 CLI (picocli) — user / tag / reply / text / profile │ 任务层 TaskScheduler → UserMediaTask · TagSearchTask · ReplyTask … │ 服务层 GraphQLClient · MediaDownloader · AccountPool · RateLimiter │ 基础层 ConfigLoader · SQLite Storage · NamingTemplate · 日志

技术栈

Java 17+ OkHttp Jackson SQLite picocli SnakeYAML SLF4J / Logback CompletableFuture

主要模块

🔌

GraphQLClient

封装请求、Cookie 认证、Transaction-ID、限流与重试，对接 X 非官方 GraphQL 接口。

📋

Task 体系

统一 Task 接口，用户媒体、Tag、评论区、纯文本、主页等模式可独立扩展。

⬇️

MediaDownloader

并发下载、命名模板、失败重试、进度回调，结果写入本地与 SQLite。

👥

AccountPool

多账号 Cookie 管理与轮换，配合 RateLimiter 降低限流影响。

💾

Storage

SQLite 记录 tweet_id + media_url，支撑增量同步与断点续传。

⚙️

Config

YAML 配置，支持账号、代理、并发、时间范围、命名模板等。
