## 实现期发现并修掉的真问题（都有测试兜住）

1. **盘符盲区（第二次犯）**：`PathSanitizer` 的盘符正则 `^[A-Za-z]:` 会把相对路径 `a:b\c.jpg` 里的 `a:` 当成盘符，段内冒号漏清洗 → 改为 `^[A-Za-z]:(?=[\\/])`（冒号后必须跟分隔符），并加回归用例。
2. **`proxy.mode` 未显式指定时不该报错**：只给 `XMEDIA_PROXY_LIST` 多个地址会被默认 `single` 拦下 → 改为按条数推断（1=single，多=pool），显式指定时仍然校验。
3. **`Lease.open` 没占许可**：原实现只包装不取信号量，用 try-with-resources 会变成「假持锁」→ 改为 `open()` 内部 `acquire()`，测试断言许可数 1→0→1。
4. **脚本类坑**：MSYS 路径（`/d/x down`、`/tmp/...`）Java 与 Windows-Python 都不认 → 统一 `cygpath -m`；Java 17 重定向输出用平台编码（GBK）导致中文断言失败 → `-Dfile.encoding=UTF-8`；YAML 双引号里不能带反斜杠（`cygpath -w` 的产物）→ 用正斜杠路径。
